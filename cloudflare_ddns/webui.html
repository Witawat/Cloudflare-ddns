กำลังโหลด…

💡 เลือกชนิดให้ตรงกับบริการ: HTTP = เว็บธรรมดา (เช่น http://localhost:8080) · HTTPS = พอร์ต SSL เช่น 443/8443 (ต้องเป็น https://localhost:443 — ถ้าผูกเป็น http จะเจอ "Bad Request") · TCP/UDP = SSH/game/VPN (เช่น tcp://localhost:22)

ข้อควรรู้
  • ชื่อเดียวใช้ได้อย่างใดอย่างหนึ่ง: A/AAAA (DDNS) หรือ CNAME (tunnel) — Cloudflare ห้ามซ้ำชื่อกัน ต้องใช้คนละชื่อ (เช่น DDNS = home.โดเมน, tunnel = app.โดเมน)
  • Tunnel ไม่ต้องเปิดพอร์ต / ไม่พึ่ง IP — เหมาะกับ CGNAT หรือไม่อยากแตะเราเตอร์
  • DDNS เหมาะกับบริการที่ต้องรับ connection ตรง (SSH, game server)
  • บริการที่ผูก (เช่น localhost:8080) ต้องรันอยู่ ถึงจะเข้าเว็บได้
  • ผูก hostname ต้องใช้ API token ที่มีสิทธิ์ Account > Cloudflare Tunnel > Edit
  • tunnel รันตาม service — หยุด service = tunnel หยุด
  • tunnel token ใช้ได้จนกว่าจะ revoke ที่ Zero Trust

ข้อควรรู้
  • ต้องมีสิทธิ์ admin — ถ้าหน้าเว็บนี้รันเป็น service อยู่แล้ว (เปิดเองหลัง boot) การติดตั้ง/ถอน/หยุดทำไม่ได้จากเว็บ (จะตัดการเชื่อมต่อตัวเอง) — ใช้ install.bat / uninstall.bat แทน ส่วน Restart ใช้ได้เสมอ (เว็บหลุด ~10-15 วิ แล้วกลับมา)
  • รันแบบ standalone (คำสั่ง webui / เปิด exe เปล่า ๆ) ต้องเปิดด้วยสิทธิ์ admin ถึงจะติดตั้ง/ควบคุม service ได้
  • ถอนการติดตั้งไม่ลบ config/state/ข้อมูล — แค่เอา service ออกจาก Windows
